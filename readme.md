# AI-Powered Support Ticket Dashboard

This is a full-stack Minimum Viable Product (MVP) for a customer support dashboard. It features secure JWT authentication, comprehensive ticket management, and an integration with Google's Gemini AI to automatically summarize issues and suggest actions.

## 🚀 Features

* **Secure Authentication**: JWT-based session management for support agents[cite: 2, 5].
* **Rich Ticket Management**: A detailed ticket creation form capturing customer type, product area, impact, and source channel[cite: 3, 5].
* **AI-Powered Insights**: Integrates with the `gemini-2.5-flash` model to analyze tickets and provide a summary, sentiment analysis, suggested priority, next action, and an AI confidence score[cite: 2, 3, 5].
* **Detailed Dashboard**: View all tickets, filter by status or search text, update assignments, and leave internal or public comments[cite: 5].

---

## 🛠️ Tech Stack

* **Frontend**: React, Tailwind CSS, Lucide Icons[cite: 5].
* **Backend**: Node.js, Express.js[cite: 2].
* **Database**: MongoDB with Mongoose[cite: 2, 3].
* **AI Integration**: Google Generative AI SDK (`@google/generative-ai`)[cite: 2].

## ⚙️ Getting Started

Follow these steps in order to set up the database, start the API, and run the dashboard.

### 1. Environment Variables
Create a `.env` file in your backend directory with the following variables:
\`\`\`env
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=support-ai-dev-secret
GEMINI_API_KEY=your_google_gemini_api_key
CLIENT_ORIGIN=http://localhost:5173
PORT=5000
\`\`\`

### 2. Seed the Sample Data
Before starting the servers, you must seed the database. This script clears any existing data and generates our sample users, agents, and tickets[cite: 4].
\`\`\`bash
cd backend
npm run seed
\`\`\`
*Note: This creates two test agents and two sample tickets with pre-generated AI insights[cite: 4].*

### 3. Start the Backend Server
Start the Express server, which runs on port 5000 by default[cite: 2].
\`\`\`bash
cd backend
npm run dev
\`\`\`

### 4. Start the Frontend Application
Start the React development server. It is configured to communicate with the API at `http://localhost:5000/api`[cite: 5].
\`\`\`bash
cd frontend
npm start
\`\`\`

## 💡 Usage Guide

1. **Authentication**: Enter the demo credentials on the login screen to access the workspace[cite: 5]. 
2. **Ticket Queue**: Once logged in, you will see the ticket list view where you can search for tickets, filter by status (Open, In Progress, Resolved, etc.), and see your assigned tickets[cite: 5].
3. **Ticket Creation Form**: Click "New Ticket" to access the rich intake form[cite: 5]. You can record comprehensive details such as the customer's company, contact method, product area, and impact level[cite: 5].
4. **AI Insights**: Open any ticket to view its details. In the right-hand panel, click **Generate insight** (or **Refresh**) to query the Gemini API[cite: 5]. The AI will read the ticket description and return a 1-2 sentence summary, sentiment, suggested priority, and a confidence score to help you manage uncertainty[cite: 2, 5].
